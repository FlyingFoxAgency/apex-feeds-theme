# APEX Feeds theme

Custom Shopify theme for APEX Feeds, built by Flying Fox Brand Agency on top of Shopify's Horizon theme.

- Base: Shopify Horizon 4.4.0 (from github.com/Shopify/horizon, 4 Nov 2026). Horizon's own readme is in `HORIZON-README.md`.
- Design source: Figma file "AI - APEX FEEDS", page "APEX Feeds".
- Licence: Horizon's licence (`LICENSE.md`) allows a derived theme to be delivered to a merchant for use in their own store only. Keep this repo private and don't list or resell the theme.

## Working on the theme

The store is connected to this repo through Shopify's GitHub integration (Online Store > Themes > Add theme > Connect from GitHub). Each connected branch shows up as its own theme that can be previewed and published.

Local development uses the Shopify CLI:

```
shopify theme dev --store <store>.myshopify.com
```
